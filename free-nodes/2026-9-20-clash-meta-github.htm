初识 Shadowrocket：不仅仅是一个代理工具

很多人初次听到“Shadowrocket”这个名字，可能会误以为它是一款游戏或娱乐软件。实际上，它是一款运行在 iOS 系统上的高性能网络代理客户端。它的核心功能并非“创造”网络，而是“切换”与“转发”。通过接收远程服务器的代理协议（如 Shadowsocks、Vmess、Trojan 等），Shadowrocket 能够将你的网络请求加密并转发至境外节点，再由该节点向目标网站发起请求。这样一来，目标网站看到的访问者来自代理服务器所在地，而非你的真实 IP，从而巧妙地绕过了地理封锁。

与部分同类工具相比，Shadowrocket 的优势十分明显：其一，它原生支持 iOS 系统，与系统网络栈深度整合，无论是 Wi-Fi 还是蜂窝数据，都能无缝接管；其二，它支持按需路由（Rule-based Routing），你可以设置特定网站走代理、国内网站直连，从而在保证访问速度的同时，节省不必要的流量损耗；其三，它的界面设计简洁明了，没有繁琐的广告，即使是网络小白也能在几分钟内上手。可以说，Shadowrocket 不仅仅是一个工具，更是一种“网络自由”的象征。

安装篇：获取“小火箭”的曲折与智慧

在 App Store 中搜索“Shadowrocket”，你可能会发现它并不像微信、支付宝那样直接出现在结果中。这并非软件下架，而是由于地区限制，该应用仅在中国大陆以外的 App Store 区域提供。因此，安装的第一步，是拥有一个海外地区的 Apple ID。

步骤一：准备海外 Apple ID 你可以通过苹果官网自行注册一个美区或港区账号，也可以使用已有的海外账号。需要注意的是，注册时无需绑定支付方式，只需选择一个免税额度的选项即可。如果你已经拥有一个，直接跳过此步。

步骤二：切换 App Store 账号 打开 App Store，点击右上角头像，滑到底部点击“退出登录”。然后使用刚才准备好的海外 Apple ID 登录。登录成功后，再次搜索“Shadowrocket”，点击获取并下载。由于网络波动，若下载速度较慢，建议切换至稳定的 Wi-Fi 环境。

步骤三：安装后的注意事项 下载完成后，回到桌面即可看到那个蓝底白鸟的图标。首次打开时，系统会提示“未受信任的开发者”。此时需进入“设置 -> 通用 -> VPN 与设备管理”，找到对应的开发者证书并点击信任。至此，安装环节全部完成。

配置篇：从零开始，搭建你的专属通道

安装只是第一步，真正让 Shadowrocket 发挥威力的关键在于配置。很多新手在这里望而却步，其实只要按照以下逻辑操作，一切都将水到渠成。

1. 获取代理服务器信息 这是最核心的一环。你需要一个可用的代理服务器地址，通常包括服务器 IP、端口、密码以及加密方式。这些信息从哪里来？你可以选择自行租用海外 VPS 搭建，也可以购买第三方提供的付费订阅服务（通常以“机场”代称）。对于初学者，我更推荐后者，因为其配置简单、节点众多，且售后完善。购买后，服务商通常会提供一个包含“订阅链接”的二维码或 URL。

2. 导入订阅配置 打开 Shadowrocket，首页会看到一个醒目的“+”号。点击它，选择“类型”为“Subscribe”（订阅）。在“URL”栏粘贴你复制的订阅链接，点击“完成”。此时，软件会自动拉取远程服务器列表，并在首页显示一排节点。这一步骤相当于为你的“小火箭”装上了燃料，让它拥有了飞往世界各地的能力。

3. 手动配置（可选） 如果你拥有的是单节点信息，而非订阅，则同样点击“+”，选择类型为“Shadowsocks”或“Vmess”，手动填入服务器地址、端口、密码及加密方式。这里建议加密方式选择“aes-256-gcm”或“chacha20-ietf-poly1305”，安全性更高。

4. 设置代理模式与规则 配置完成后，回到主界面。你会看到顶部有“全局路由”与“配置”两个按钮。点击“全局路由”，选择“配置”而非“代理”或“直连”。在“配置”模式下，Shadowrocket 会根据内置规则自动分流：访问谷歌、YouTube 时走代理，访问国内网站时直连。这样既能保证速度，又能避免国内应用因代理 IP 而出现地域限制。如果你追求极致简单，可以暂时选择“代理”模式，即所有流量均走代理，但这样会略微拖慢国内网站的加载速度。

5. 开启连接 一切就绪，只需将主界面右上角的开关拨至绿色。首次连接时，系统会弹出“允许添加 VPN 配置”的提示，点击“允许”并输入设备密码。之后，状态栏会出现一个“VPN”图标，这意味着你的网络流量已经成功进入加密隧道。

实战篇：穿越“高墙”，拥抱谷歌

当 VPN 连接建立后，你可能会迫不及待地打开 Safari 浏览器，输入 www.google.com。但稍等，如果页面显示“无法访问此网站”，请先不要慌张。这通常是因为 DNS 缓存尚未刷新。解决方法是：断开 Shadowrocket，关闭 Wi-Fi，重新开启 Wi-Fi，再连接 Shadowrocket。或者，在 Shadowrocket 的设置中，将 DNS 设置为“1.1.1.1”或“8.8.8.8”，这能有效避免 DNS 污染。

常见问题与技巧点评：让你的“小火箭”飞得更稳

在实际使用中，你可能会遇到一些小问题。比如，为什么网速有时快有时慢？这取决于你当前连接的节点负载。建议在 Shadowrocket 主界面，点击右上角的“延迟测试”按钮（闪电图标），选择延迟数值最低（如 50ms）的节点。又比如，为什么某些 App 无法联网？这是因为这些 App 可能屏蔽了 VPN 连接。解决办法是，在 Shadowrocket 的“配置”中，找到“规则”选项，为这些特定 App 添加“直连”规则。

FAQ

V2Ray 配置文件中 inbound 和 outbound 有什么区别？
在 V2Ray 中，inbound 表示流量进入方式（如本地代理端口），outbound 表示流量出口方式（如 VMess、Trojan 等协议）。通过灵活组合两者，可以实现局域网共享、分流及中继等功能。
VMess 使用 TLS+WebSocket 的好处是什么？
TLS+WebSocket 可伪装成正常 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可在高封锁网络环境下保持安全、稳定和高速的网络访问体验。
Nekobox 如何设置分流规则？
Nekobox 提供图形化规则编辑界面，可基于 IP、域名、地区等条件创建分流规则。例如可设置国内直连、国外代理、特定网站走特定节点，操作直观。
SSR 是否还值得使用？
虽然 SSR 的开发早已停止，但由于它配置简单且部分节点仍然兼容，仍有一定使用场景。不过建议用户逐步迁移到更安全的新协议如 VLESS 或 Trojan，以获得更佳性能与隐蔽性。
如何使用 Clash 配置订阅链接？
在 Clash 中添加订阅链接时，用户需复制提供的 URL 并在客户端的配置界面中粘贴。Clash 会自动下载并更新配置文件。通过订阅，用户可以一键更新节点信息，无需手动导入，适合长期维护多个节点来源的用户。
如何将 Clash 节点导入到 Sing-box？
Sing-box 支持从 Clash 配置文件中导入节点。用户只需将 YAML 文件放入配置目录或通过命令导入即可。系统会自动解析规则组和节点信息，简化迁移过程。
WinXray 的内核能否替换？
可以。WinXray 的内核文件独立存在于程序目录中，用户可替换为最新的 v2ray-core 或 xray-core 文件以获取更好的性能与协议支持，但需保持版本兼容。
Clash 的配置文件是 YAML 格式吗？
是的。Clash 的配置文件采用 YAML 格式，结构清晰易读。用户可以通过编辑 proxies、proxy-groups 和 rules 部分来自定义节点列表、分组策略和分流规则，非常灵活。
V2Ray 如何通过策略组优化访问速度？
策略组允许用户将节点按延迟、地域或用途分组。结合路由规则，V2Ray 会自动选择最优节点处理流量，提升访问速度并降低延迟，尤其在访问海外网站时效果明显。
QuantumultX 如何实现按端口和协议分流？
QuantumultX 支持按 TCP、UDP、端口及应用协议分流流量，结合策略组选择最优节点。可为游戏、视频和广告屏蔽提供最佳网络体验，提高访问速度和稳定性。
